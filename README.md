# AI Resume ATS System

AI-powered resume screening with semantic matching, ATS scoring, and intelligent feedback.

## Features
- TF-IDF Semantic Matching
- Keyword Extraction & Comparison
- ATS Score (0-100)
- AI Feedback & Recommendations
- Scan History Dashboard

## Tech Stack
- Streamlit
- scikit-learn (TF-IDF + Cosine Similarity)
- SQLite
- NLP
